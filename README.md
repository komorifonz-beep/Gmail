# 朝のメール仕分け — 無人化ガイド

毎朝の「朝のメール仕分け」が**ツール実行のたびに許可を求めてくる**問題を解消し、
レイバー資料メールと同じように黙って動くようにするための手順書と設定一式です。

---

## 結論（先に読む3行）

1. 許可を求めてくるのは **Claude Code の許可プロンプト**。設定ファイルに許可リストを
   書けば消えます。まず [`settings/settings.example.json`](settings/settings.example.json) を
   `~/.claude/settings.json` にマージしてください。
2. レイバー資料メールが黙って送れているのは、あれが **Claude を介さない素のスクリプト**
   だからです。承認を求める相手がそもそも居ません。
3. クラウドへの移行は**不要**です。いまのPC版は「本物の自分宛送信・SENTに残る・
   `5,メール仕分け` ラベルが付く」を実現できており、クラウド版ではそこまで再現できません
   （詳細は[後述](#なぜクラウドに移さないのか)）。

## 調べて分かったこと

### 自動送信は2系統あり、性質がまったく違う

送信済みメールの**時刻のばらつき**を見ると、どちらが機械でどちらが人間かがはっきり出ます。

| メール | 送信時刻(UTC) | ばらつき | 正体 |
|---|---|---|---|
| `レイバー資料 YYYY年M月D日` | 22:37:39 / :41 / :43 / :46 / :48 / 22:38:04 / 22:39:05 | **±90秒** | スケジューラで回る素のスクリプト |
| `朝のメール仕分け M/D` | 00:59:46 / 01:10:04 / 01:12:34 / 02:12:34 / 03:12:35 | **2時間以上** | **人が手で起動している** |

仕分けの起動時刻は 9:59〜12:12 JST の間でばらついています。機械なら毎日ほぼ同じ秒に走るので、
これは毎朝ご自身で起動して、出てくる許可プロンプトをクリックしている、ということです。
つまり潰すべきは「許可プロンプト」と「手動起動」の2つで、**前者だけ潰しても効果は大きい**。

### ついでに見つかった既存のバグ

8/10 に送信されたレポートは、**件名が `朝のメール仕分け 8/10(月)` なのに本文の見出しが
`📬 8/8(土) 朝のメール仕分け`** になっています。日付の算出が2日ずれています。
[`prompt/朝のメール仕分け.md`](prompt/朝のメール仕分け.md) では実行日(JST)で統一するように直してあります。

## なぜクラウドに移さないのか

クラウド（Claude Code on the web）側の Gmail コネクタには**メール送信ツールがありません**
（`create_draft` / `update_draft` はあるが `send` が無い）。加えて実行環境は HTTPS 以外の
通信が遮断されているため、SMTP による送信もできません（実際に接続を試して確認済み）。

つまりクラウドに移すと、いまできている以下が失われます。

- 自分宛に**本物のメールとして送信**すること
- 送信済み（SENT）に残ること
- `5,メール仕分け` ラベルが付いて後から追えること

レポートは「ルーティンの完了通知メール＋スマホPush」という別経路でなら届けられますが、
上記3点は再現できません。**いまのPC版の方が出来がいい**ので、そちらを無人化します。

> PCが落ちている日も動かしたい、という要件が出てきた場合は、そのときにクラウド版を
> バックアップとして追加できます（レポートは完了通知での配信になります）。
