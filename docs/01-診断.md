# 01. 診断 — いま何がどう動いているかを特定する

対処の前に、3つだけ確定させます。ここが分かれば次の手が一意に決まります。

- **A. Gmailツールの正式名称**（`mcp__Gmail__...` か `mcp__claude_ai_Gmail__...` か）
- **B. 仕分けは手動起動か、スケジュール実行か**
- **C. レイバー資料メールを送っているスクリプトの場所**

---

## A. Gmailツールの正式名称を確定する

**これが全ての前提です。** 許可リストは名前が1文字でも違うと効きません。

### 方法1: `/permissions` を見る（推奨）

PCで Claude Code を開き、次を入力します。

```
/permissions
```

Gmail関連のツールが正式名称で並びます。次のどちらの形かを確認してください。

| 表示 | 意味 |
|---|---|
| `mcp__Gmail__create_draft` | ローカル設定のMCPサーバ経由 |
| `mcp__claude_ai_Gmail__create_draft` | **claude.ai コネクタ経由**（こちらの可能性が高い） |

### 方法2: 次に出る許可プロンプトを見る

いつもどおり仕分けを実行し、許可を求められたときの**ツール名の表示**を控えます。
これが正式名称です。

> **控えた名前をメモしてください。** 次の [`02-許可プロンプトを消す.md`](02-許可プロンプトを消す.md)
> でそのまま使います。

---

## B. 仕分けは手動起動か、スケジュール実行か

送信済みメールの時刻から**手動起動の可能性が高い**と見ていますが、念のため確認します。

### Windows の場合

PowerShell を開いて実行:

```powershell
Get-ScheduledTask | Where-Object { $_.TaskName -match 'mail|claude|仕分|labor|レイバー' } |
  ForEach-Object {
    [PSCustomObject]@{
      Name = $_.TaskName
      Path = $_.TaskPath
      Exec = $_.Actions.Execute
      Args = $_.Actions.Arguments
    }
  } | Format-List
```

GUI で見たい場合は「タスクスケジューラ」→「タスクスケジューラ ライブラリ」を目視。

### macOS の場合

```bash
crontab -l
ls -la ~/Library/LaunchAgents/
launchctl list | grep -iE 'mail|claude|labor'
```

### 判定

| 結果 | 意味 | 次にやること |
|---|---|---|
| **仕分けのエントリが無い** | 毎朝手動で起動している（本命） | [`02`](02-許可プロンプトを消す.md) で許可を消す → [`03`](03-完全無人化.md) でスケジュール化 |
| 仕分けのエントリがある | 既にスケジュール実行されている | コマンドライン（`Args`）を控えて [`02`](02-許可プロンプトを消す.md) へ |

エントリがあった場合、`Args` に `-p` や `--print` が含まれているかを見てください。
**含まれていなければ対話モードで起動している**＝それがプロンプトの原因です。

---

## C. レイバー資料メールの送信スクリプトを見つける

こちらは確実にスケジュール実行されています（毎日 22:37Z 前後、ばらつき±90秒）。

上の B と同じコマンドで `レイバー` や `labor` にマッチしたエントリの `Exec` / `Args` を見ます。
Python スクリプトのパスが出てくるはずです。

```
例: C:\Python311\python.exe  D:\scripts\send_labor_mail.py
```

**このスクリプトの送信部分が資産です。** 仕分けの結果メールも、Claude に送らせるのではなく
このスクリプトと同じ方式（Python + SMTP）で送るようにすれば、承認を求める箇所が
構造的に消えます。[`02`](02-許可プロンプトを消す.md) の「手3」で使います。

スクリプトが見つかったら、その中の SMTP 送信部分（`smtplib` を使っているあたり）を
控えておいてください。

---

## 診断結果メモ欄

埋めてから次に進んでください。

```
A. ツール名の接頭辞:  mcp__Gmail__  /  mcp__claude_ai_Gmail__   ← どちらか
B. 仕分けの起動方法:  手動  /  スケジュール（コマンド:            ）
C. 送信スクリプト:    パス（                                      ）
```

想定と違う仕組み（Google Apps Script、n8n、Zapier など）が出てきた場合は、
この結果を持ち帰っていただければ対処を書き直します。
